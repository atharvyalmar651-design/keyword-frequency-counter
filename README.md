
# Keyword Frequency Counter using Hash Table

## About the Project
The Keyword Frequency Counter is a Python application that analyzes text and counts the frequency of each word using a hash table. It provides a graphical user interface built with Tkinter.

## Features
- Count total words and unique keywords
- Calculate the frequency of each word
- Search for keywords
- Sort keyword frequencies
- Inspect the hash table
- Export results to CSV
- User-friendly graphical interface

## Technologies Used
- Python
- Tkinter
- Hash Table
- Regular Expressions
- CSV

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python keyword_frequency_counter.py
```
